# 关注会话工作台

把多个工作区的重要会话放进同一个原生多会话工作台。

- 一键关注、批量添加与真实会话标题搜索。
- 实时摘要卡片、左右双屏、上下双屏、四宫格。
- 分屏复用 DSH 原生 Conversation：Markdown、工具卡片、附件、输入、审批等遵循原生能力。
- 独立会话作用域、最大化和拖动分隔线；原生滚动与历史加载。
- 关注与布局保存在当前配置档。
- 快捷键导航与「⌨ 快捷键」设置：总开关、逐项启停、局内/局外、录制改绑与恢复默认；保存确认后生效。

**不再是只读模式。窗格内可直接输入和处理请求；移出分屏仍不会取消关注或停止任务。**

插件不会在展示时自动发送消息、停止任务或批准请求。对原生输入和审批的用户操作会正常作用于对应会话。旧格式会话需到原会话处理升级。没有后台通知或自动摘要。
