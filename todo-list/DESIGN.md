# 待办清单（To Do List）插件设计

- 状态：**已确认并实现**（v1，2026-11-03；v1.1 条目切换组，2026-11-09）
- 目标版本：v1.1（v1「标准」+ 条目切换组）
- 与现有插件同一套做法：纯前端 bundle、`localStorage`、中英双语、主题 token

## 1. 定位

一句话：**输入框旁随手记一笔，左侧栏里认真管。**

- 输入框下方 dock：轻量快速添加 + 今日/过期一眼可见，不打断对话。
- 左侧栏图标 + 整页面板：分组、截止日期、优先级、筛选、排序。

不做「第二个 Notion」：v1 不碰子任务、重复任务、标签、提醒通知、跨设备同步。

## 2. 两个呈现面

### 2.1 dock：快速添加 + 今日概览

折叠态（`conversation.composer.dock`，与番茄钟并排）：

```text
┌──────────────────────────────────────────────────────────────┐
│  [☑ 待办]  [今日 1/3]  [＋ 添加]  │  ← 一行环境控件           │
└──────────────────────────────────────────────────────────────┘
```

- `今日 1/3`：分母 = 今天到期（due = 今天）的任务数，分子 = 其中已完成数；没有今日任务时只显示 `待办`。
- 有逾期任务时 `＋` 旁出现红色小点 / 数字（`过期 2`）。
- 点主按钮「待办」或 `＋` 打开向上弹层（宽约 320px，最高 60vh，内部滚动）：
  - **快速添加**输入框（打开即聚焦，Enter 添加并保持焦点，可连续录入；Esc 收起）
  - **已过期** 区块（红色标题，勾选/取消）
  - **今天** 区块（未完成在上，今天已完成折叠成一行 `已完成 2`，点开显示）
  - 底部提示：`完整清单在左侧栏「待办」`，不在此处跳转（避免依赖内部导航 API）
- 关闭：Esc、点弹层外、再次点触发按钮；用 Esc 关闭时焦点回到主按钮。
- 快速添加落地：**今天到期、收件箱、无优先级**（已确认，2026-11-03）。

### 2.2 侧栏图标 + 整页

`sidebar.panellist`（order 30，排在九宫格之后）+ `main` 键位 `todo-list`。

```text
┌ 待办清单                                     [导出] [导入] [复制 MD] [帮助] ┐
│ 全部 12            │  全部 | 今天 | 过期 | 已完成          │
│ 收件箱 5           │  ┌ 添加待办…（回车保存，可带分组）      │
│ 工作 4             │  ☐ 写周报                    今天  ●高  × │
│ 生活 3             │  ☐ 约牙医                    明天       × │
│ + 新建分组         │  ☑ 买菜                      已完成     × │
│                    │  …                                      │
└────────────────────┴────────────────────────────────────────┘
```

- **左栏分组**：`全部`、内置`收件箱 / 工作 / 生活`、用户自建分组；每组右侧显示未完成数。选中态高亮。内置分组固定，不可改名或删除；自建分组可重命名 / 删除。分组项同时是任务拖放目标（悬停高亮，见 §10）。
- **右栏顶部筛选**（对当前分组生效）：
  - `全部`：未完成任务
  - `今天`：`due = 今天` 且未完成
  - `过期`：`due < 今天` 且未完成
  - `已完成`：已完成任务，按完成时间倒序
- **添加行**：位于列表上方。当前分组明确时直接加入该组；选`全部`时带一个分组下拉（默认收件箱）。在`今天`筛选下添加会自动设为今天到期；在`过期` / `已完成`筛选下添加后自动切回`全部`，避免新任务被筛掉。
- **任务行**：
  - 左侧拖拽手柄（HTML5 drag），在**同一分组内**手动排序；筛选状态下排序写回全局顺序；拖到左栏分组则切换分组
  - 勾选框：切换完成（完成时间记入 `doneAt`）
  - 标题：点击就地编辑，Enter / 失焦保存，Esc 取消，清空则保持原标题
  - 元信息：分组徽标（始终显示、可点击切换分组，见 §10）、截止日期徽标（`今天` / `明天` / `已过期 N 天` / `M月D日`）、优先级三格色条（高红 / 中黄 / 低蓝，全部使用主题 token）
  - 右侧 `×` 删除（悬停显示；点第一次进入行内二次确认，点「确认删除」才移除，不弹窗）
- **日期**：点日期徽标弹出小面板 = 原生日期选择 + `今天` / `明天` / `清除`。日期按本地时区的 `YYYY-MM-DD` 字符串保存，比较用本地日期键，避免时区偏移。
- **优先级**：点色条循环 `无 → 低 → 中 → 高 → 无`，aria-label 同步朗读当前级别。
- **分组管理**：`+ 新建分组`（名称必填、去重、最多 20 字）；自定义分组可重命名 / 删除，删除时其任务移入收件箱（二次确认文案说明）。内置三个分组固定。
- **空状态**：分组为空、筛选无结果、完全没有任务，分别给不同提示。
- **响应式**：视口 < 720px 时左栏收成横向可滚动分组条。

## 3. 数据模型

存储键：`dsh-todo-list/v1`（与其他插件一致，纯浏览器本地，不经 Host、不上传）。

```jsonc
{
  "version": 1,
  "groups": [
    // 只存自建分组；内置「收件箱 / 工作 / 生活」是常量，名称走 i18n
    { "id": "g_xxxxxxxx", "name": "阅读计划", "order": 3 }
  ],
  "tasks": [
    {
      "id": "t_xxxxxxxx",
      "title": "写周报",
      "done": false,
      "doneAt": null,
      "due": "2026-11-03",          // 可为 null
      "priority": "none",            // none | low | medium | high
      "groupId": "inbox",
      "order": 0,                    // 同组内顺序，越大越靠后；换组后为 max+1，允许空洞
      "createdAt": 1762137600000,
      "updatedAt": 1762137600000
    }
  ]
}
```

- 内置分组名走 i18n（`收件箱` / `Inbox` 等），不存中文；数据里只有自建分组。
- UI 选中态（分组 + 筛选）另存 `dsh-todo-list:ui/v1`，不进导出文件。
- 读写集中在 store：`load()` 解析失败时回退空数据并给出提示，不抛错；`save()` 失败（如隐私模式）提示「本机无法保存」。
- 日期工具：`todayKey()`、`addDaysKey()`、`parseDayKey()`、`dayDiff()`、`formatDue()`，全部用本地时间（日期键 `YYYY-MM-DD`，比较时转 UTC 日历日，避开时区与 DST）。
- id：优先 `crypto.randomUUID()`，无则时间戳 + 随机串。

## 4. 导入 / 导出

- **导出 JSON**：`{ version: 1, exportedAt, groups, tasks }`，文件名 `todo-list-YYYY-MM-DD.json`。
- **导入 JSON**：校验 `tasks` / `groups` 结构；**按 id 合并**，冲突时 `updatedAt` 新者胜；不删除本机已有任务；结果提示「新增 N 条、更新 M 条、跳过 K 条」。
- **复制为 Markdown**：按分组输出 `- [ ] 标题（日期 · 优先级）`，已完成用 `- [x]`，便于贴进笔记或发给 Agent。

## 6. 实现要点

- `window.__ModuleLoader__.load({ id: '@local/todo-list', factory(require) { … } })`，只 `require('react')`，不引内部包。
- 复用番茄钟的 store 模式：模块级数据 + 订阅，组件用 `useState` + `useEffect` 订阅；写入即 `persistData()`（本地数据量小，无需防抖批次）。
- 两个 slot 共享同一 store，dock 勾选与整页改动实时同步。
- 样式内联注入（`<style>`），类前缀 `.tdl-`；颜色只用 `--dsw-alias-*` token，跟随浅色/深色；优先级色以 token + `color-mix` 表达，不写死主题色。
- i18n：`ctx.locale.register(NS, 'en'|'zh', DICT)`，`ctx.locale.bind(NS)`；新文案全部进词典。
- 可访问性：所有图标按钮有 `aria-label`；`focus-visible` 有描边；弹层支持 Esc 关闭与 `aria-expanded`；勾选框用原生 `input[type=checkbox]`。

## 9. 已确认的决策（2026-11-03）

1. **dock 快速添加**：默认落到「今天到期」的收件箱任务，无优先级。
2. **删除任务**：行内二次确认（`×` 旁出现「确认删除 / 取消」），不弹窗。
3. **默认分组**：预置 `收件箱 / 工作 / 生活` 三个内置分组，固定不可删改；其余自建。
4. 以上均已按此实现；v1 不做提醒与子任务。

## 10. v1.1：条目切换组（2026-11-09）

### 10.1 交互

- **分组徽标（主入口）**：任务行的分组徽标从静态标签改成按钮，任何视图（`全部` 与单个分组）都显示；点击弹出分组菜单，列出内置与自建分组，当前分组打勾。有键盘焦点与 `aria-haspopup="menu"` / `aria-expanded`；菜单支持 ↑/↓ 移动焦点、Esc / 点外部 / 滚动关闭。窄屏（<720px）不再隐藏徽标，保证移动端也能换组。
- **拖到左栏分组（快捷入口）**：把任务左侧手柄拖到左侧栏任一分组上，悬停时目标分组高亮，松手即换组；拖回原分组是 no-op，不改变顺序，也不高亮。
- **反馈**：整页标题下方短暂提示「已移到「分组」」；任务从当前分组列表消失，左栏计数、Markdown 复制与 JSON 导出随之更新。

### 10.2 移动语义

- 只改 `groupId` 与 `order`：排到目标分组末尾（`max(order)+1`，空组为 0），并刷新 `updatedAt`。
- 不改标题、截止日期、优先级、完成状态与 `doneAt`；`done` 任务同样可以换组。
- 数据版本仍为 `1`，不新增字段，不需要迁移；旧备份导入后照常可用。
- 目标分组校验：只接受内置或已存在的自建分组；同组移动直接返回，不写存储、不提示。

### 10.3 自动验证

`tests/todo-list.test.js`（随仓库提交，无 npm 依赖）用 fake `window` + 最小递归 React 渲染真实组件树，24 项检查覆盖：分组菜单内容与当前项、点选换组与目标组末尾排序、同组 no-op、自定义 / 空白分组、拖放换组与高亮、同组拖放、单分组视图内换组、Esc / 外部点击 / Tab 关闭、视图切换自动关闭、`aria-expanded`、已完成任务换组、侧栏计数、刷新恢复、未知分组与保留 id `all` 回退、英文界面、Markdown 导出与新增任务回归。
