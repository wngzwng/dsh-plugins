# 待办清单 (To-do List)

DeepSeek Harness Web UI 的待办插件。两个入口共用一份数据：输入框下方的
`conversation.composer.dock` 用来随手记，左侧栏图标点开是整页的任务管理面板。

## 功能

- **输入框旁快速添加**：dock 显示「待办」与今日进度（如 `今日 1/3`），有逾期任务时
  显示红色「过期 N」；点 `＋` 打开弹层，输入回车即添加为**今天到期**的收件箱任务，
  弹层里还能直接勾掉今天和过期的任务。
- **整页管理**（`sidebar.panellist` + `main` 键位 `todo-list`）：
  - 分组：内置 `收件箱 / 工作 / 生活` 三个固定分组，可自建、重命名、删除分组
    （删除时组内任务移到收件箱）。
  - 切换分组：点任务行的分组徽标弹出分组列表，选中即移动；也可以把任务左侧手柄
    拖到左侧栏的分组上。移动后排到目标分组末尾并提示结果，在任意分组视图里都能换组。
  - 截止日期：点日期徽标弹出日期选择，或一键 `今天 / 明天 / 清除`；过期任务标红。
  - 优先级：点三格色条循环 `无 → 低 → 中 → 高`，高/中/低分别用主题 token 上色。
  - 筛选：`全部 / 今天 / 过期 / 已完成`，与当前分组组合生效；已完成页可一键清空。
  - 排序：拖动任务左侧手柄在同组内手动排序；拖到左侧栏分组则是换组。
  - 标题就地编辑，删除在行内二次确认（不弹窗）。
  - 在「今天」筛选下添加任务会自动设为今天到期；其他筛选下添加会自动回到「全部」，
    避免新任务被当前筛选藏起来。
- **备份**：`导出 JSON`、`导入 JSON`（按任务 id 合并，`updatedAt` 新者胜，不删除本机
  任务）、`复制为 Markdown`（按分组输出清单）。
- 界面文案走 Harness 客户端 `locale` 服务，支持中文 / 英文；颜色全部使用
  `--dsw-alias-*` 主题 token，跟随浅色 / 深色主题。
- 存储读取失败或不可写时降级为空清单并给出提示，不会白屏。

## 数据

数据保存在当前浏览器 `localStorage`，不经过 Host、不上传：

| 键 | 内容 |
| --- | --- |
| `dsh-todo-list/v1` | 任务与自建分组（内置分组只存 id，名称走 i18n） |
| `dsh-todo-list:ui/v1` | 上次选中的分组与筛选，仅本机使用，不进导出文件 |

换浏览器、清缓存或换设备前，请用右上角「导出 JSON」留一份备份。

## 结构

| 文件 | 作用 |
| --- | --- |
| `package.json` | 包清单：`dsh.bundle.patch` + `dsh.client`（web，立即加载） |
| `cordis.patch.yml` | 插入 Host 行 `todo-list` |
| `index.js` | Host 半：空实现，只提供插件清单条目 |
| `client.js` | 浏览器半：store、dock 快速添加、整页面板、样式、i18n |
| `locale/en.json`, `locale/zh.json` | 插件管理器标题与描述 |
| `icon.svg` | 原创图标（清单卡片 + 勾选框） |
| `DESIGN.md` | 设计稿与决策记录（不随 bundle 发布） |

## 安装

通过 DSH 的 Plugin Manager 安装本目录（bundle），或在会话里由 Agent 执行
`plugin_manager install_bundle`，target 指向本目录绝对路径。安装后：

- 输入框下方出现「待办」控件；
- 左侧栏出现待办图标，点开是整页面板。

装好后如果界面没有立即变化，重启 DSH 或刷新页面。

## 说明与限制

- 纯前端插件，不依赖 Harness 内部包，只从共享模块表取 `react`。
- v1 不含子任务、重复任务、标签、搜索、提醒通知、跨设备同步；Agent 也还不能直接
  读写任务（数据在浏览器里）。需要进阶能力时再迭代。
- 拖拽排序仍只在同组内调整顺序；跨组请用「拖到左侧栏分组」或点分组徽标，键盘排序暂未提供。
