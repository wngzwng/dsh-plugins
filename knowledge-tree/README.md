# 知识树 (Knowledge Tree)

DeepSeek Harness Web UI 的知识梳理插件：**先列举、再归类、最后成树**，三个阶段锁死顺序，
侧栏多一个图标，点开就是整页的知识树工作台。

## 三个阶段

顺序是故意锁死的，每个阶段解决一种失败：

| 阶段 | 你要做的 | 系统替你挡的 |
| --- | --- | --- |
| ① 列举 | 一条一条写：标题必填，内容可选 | 边写边分类，清单越写越少 |
| ② 归类 | 在自动排布的白板上把卡片拖到目标卡片上 | 手工摆版式，摆完没力气判断归属 |
| ③ 成树 | 只做裁决：改名、调顺序、补内容、导出 | 环、过宽、关联，系统检查出来 |

出门条件：列举至少 2 张；归类必须没有「待整理」；成树要处理完结构检查项。

## 知识卡片

一张卡 = **标题 + 内容 + 可选的一张配图**：

- 标题必填、一句话，是树节点的名字；内容可选，放解释、例子、来源。
- **图片**：粘贴截图（展开卡片后 Ctrl/⌘+V）、把图片拖到卡片上、或点「＋ 图片」选文件；
  自动压到长边 ≤1280px、WebP、≤420KB，展开后显示缩略图，点图看大图，可更换 / 移除。
- **默认收起，只显示标题**；点卡片展开看内容，再点收起。
- 收起态也显示状态与归属：`待整理`、`N 个子项`、`N 个关联`、`→ 主题名`、`顶层主题`。
- 展开后可改归属、添加关联、设为顶层主题、取消归类。

## 归类：自动布局的白板

所有卡片落在同一块白板上，**位置由插件排，你只负责连接**：

- **引导语可编辑**：列举阶段顶部「引导」旁的「编辑」，可以增删改提示语、恢复内置的 12 条；
  改完点「换一个」在自定义列表里轮换，只存本机。
- **新建主题**：几条知识共同的上位主题还不存在时，点「＋ 新建主题」，创建后再把它们拖进去。
  主题创建即顶层主题，不进入待整理。
- **补一条知识**：归类时就地补录，落在「待整理」。
- 把卡片拖到另一张卡上 = 归入它；**按住 Shift** 拖放 = 添加关联（同一张卡在另一主题下再出现一次，不是复制）。
- **拖放预告**：拖动时提示条显示「将「A」归入「B」」，目标卡片高亮。
- **顶层有专门投放区**：拖到「设为顶层主题」区域才设为顶层；拖到画布空白处不会修改任何数据，并提示原因。
- **三种状态**：待整理（虚线 + 角标）/ 顶层主题 / 已归入上级（`→ 主题名`），
  顶部摘要 `待整理 / 顶层主题 / 已归入上级` 的数字都来自真实数据。
- 只有「待整理 0」时才能进入下一阶段；「其余设为顶层主题」可一键清空。
- 把节点挂到自己的子孙下会被拒绝（防环）；每步可撤销（50 步）。
- 卡片展开区有「改归属…」「添加关联…」「设为顶层主题」「取消归类」，对话框可搜索，
  是键盘 / 触屏的等价入口。

## 成树

- **结构检查**：主层级有环才报错（可一键断开）；额外交联作为**关联 N 处**单独列出（改为主归属 / 移除关联）；
  多个顶层主题与过宽分支只提示。
- 只有真的检查过且无环才显示「结构检查通过」；「可以导出」单独说明，不暗示内容或分类已被确认。
- **大纲编辑**：改标题、展开看内容、编辑内容、折叠子项、加子项、删除（子项上提）、同级上移 / 下移、
  拖动改父。**树形预览**：只读，看整体形状。
- **树名**是文档名，不是根节点：有独立标签与说明，只改名称不影响结构，导出文件名也用它。
- **保存状态**：页脚与工具栏显示「已保存到本机 · HH:MM」（只在写入成功后出现）；
  写入失败显示「未保存：浏览器拒绝写入」。
- 顶部「上一步」在成树阶段是「回到归类（改归属）」，全流程只有这一条回到结构编辑的路径。

## 导出

右上角「导出」按有没有配图分两种组合：

- **没有图片**：Markdown 大纲（`- 标题`，内容为 `> 引用` 行，关联为 `↪ 另关联：…`）+ 单个 HTML 文件。
- **有图片**：ZIP（`tree.md` + `images/`，Markdown 里用相对路径引用）+ 单个 HTML 文件（图片内嵌，单文件可看）。

两种情况下都另有 Mermaid `mindmap`（只含标题）、JSON 备份（含图片，可再导入并按 id 合并）、
复制纯文本大纲（只含标题）。导出包含全部卡片、关系与图片，**不受折叠或当前视图影响**。
成树阶段另有「复制 Markdown」一键按钮（纯文本，不含图片）。

## 数据

只保存在当前浏览器 `localStorage`：

| 键 | 内容 |
| --- | --- |
| `dsh-knowledge-tree/v3` | 阶段、树名、卡片（标题 / 内容 / 配图 / 归属状态）、链接（主归属 / 关联） |
| `dsh-knowledge-tree:ui/v2` | 视图偏好、折叠 / 展开状态、引导语轮换位置 |
| `dsh-knowledge-tree:prompts/v1` | 自定义引导语（未自定义时使用内置 12 条；不随 JSON 导出） |

从 v1 / v2 升级时自动迁移（`text → title`、`note → content`）。图片以 data URL 内嵌在同一条记录里，
所以整棵树仍是一个自包含的 JSON 备份；代价是 **localStorage 约 5MB**，按压缩后约 40–300KB/张计算，
大约 15–25 张图。不经过 Host、不上传。
换设备或清缓存前请导出 JSON 备份。数据损坏时降级为空树并提示，不白屏。

## 结构

| 文件 | 作用 |
| --- | --- |
| `package.json` | 包清单：`dsh.bundle.patch` + `dsh.client`（web，立即加载） |
| `cordis.patch.yml` | 插入 Host 行 `knowledge-tree` |
| `index.js` | Host 半：空实现，只提供插件清单条目 |
| `client.js` | 浏览器半：store、三阶段页面、白板自动布局、树视图、导出、i18n、样式 |
| `locale/en.json`, `locale/zh.json` | 插件管理器标题与描述 |
| `icon.svg` | 原创图标（树形节点） |
| `DESIGN.md` | 设计稿与决策记录（不随 bundle 发布） |

## 安装

通过 DSH 的 Plugin Manager 安装本目录（bundle），或在会话里由 Agent 执行
`plugin_manager install_bundle`，target 指向本目录绝对路径。安装后左侧栏出现知识树图标。

## 已知限制

- 拖动依赖 HTML5 drag-and-drop，触屏浏览器不触发；用卡片展开区的按钮等价操作。
- 白板不做手工摆放（那会退化成手工排版），也不用力导向（会漂移）；规则见 DESIGN 第 4 节。
- 树形预览只读；改归属统一回到归类白板。
- 同级排序用 ↑ / ↓ 按钮，不做拖拽插入位。
- 阶段切换会重置白板滚动位置；展开 / 折叠状态保留。
- 每张卡最多一张图；图片体积受浏览器 localStorage 配额限制（见上），写满时会提示且不保存该图。
- GIF 按原文件保存（≤420KB），更大的 GIF 会被拒绝；不做图片标注、裁剪或相册。
- 引导语是本地的可编辑列表（内置 12 条），不接模型追问；自定义列表只存本机，不随 JSON 导出。
- 英文界面为尽力而为的翻译，不作为硬性兼容要求；自定义引导语不按语言分存。
