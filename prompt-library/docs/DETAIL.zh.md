# 提示库

把散落在聊天、备忘录和网页里的提示词集中保存，用标签、收藏、置顶、评分和搜索快速找到，并复制或安全插入当前会话草稿。

## 功能

- **侧栏整页管理**：搜索（标题 / 正文 / 标签）、标签分类、收藏、置顶、最近使用、1～5 星半星个人评分与「待复评」、评价备注。
- **输入框旁快捷面板**：按全部 / 置顶 / 收藏 / 最近使用分类浏览，复制正文，或插入到光标处（可撤销，不覆盖整份草稿）。
- **快速收录**：粘贴文本、整份输入框草稿、对话中选中的文本；收件箱整理状态、自动标题、重复提醒、来源元数据。
- **正文显示**：默认纯文本，可切换只读 Markdown 预览；不执行 HTML，不加载远程图片。
- **导入导出**：CSV 用于交换，JSON 用于完整备份。
- **可选 AI 辅助评价**：仅在你主动点击时调用，复用 DSH 已配置的模型，输出不超过 200 字，只作参考，不替代个人评分。

## 安装

在 DSH 的「插件市场」搜索「提示库」一键安装；或从 [Releases](https://github.com/wngzwng/dsh-prompt-library/releases) 下载 tgz 后执行：

```bash
dsh plugin --profile web add https://github.com/wngzwng/dsh-prompt-library/releases/download/1.0.0/wngzwng-dsh-prompt-library-1.0.0.tgz
```

## 使用

- 左侧栏「提示库」打开整页管理；输入框工具栏「提示库」打开快捷面板。
- 数据保存在当前浏览器；换设备或清理浏览器数据前，请先导出 JSON 备份。

## 数据与隐私

- 提示词、标签、评分、AI 评价与来源元数据只保存在本机浏览器，不上传。
- AI 评价由 Host 侧调用 DSH 模型服务，浏览器不接触密钥；每次调用可能产生模型费用。
- 分享与复制只包含标题和正文，不包含评价备注与 AI 评价。
