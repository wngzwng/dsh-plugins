# 人生九宫格 (Life Grid)

DeepSeek Harness Web UI 的年度九宫格插件，方法参考《只管去做》（邹小强）第二章
「让梦想照进现实」。左侧栏多一个九宫格图标，点开就是整页的年度规划面板。

## 九宫格的定义（书里的用法）

八个生活领域围绕中心格，中心写年度主题/愿景，用来做两件事：

1. **愿景盘点**：把五年信里的愿景放进八个领域，检查哪些领域被忽略、哪些被挤占。
   平衡不等于平均分配，允许阶段性偏重，但要看清对其他领域的影响。
2. **三步转化**：先定义（用自己的话说明"变好"的样子）→ 再计划（比较现状与愿景、
   选路径）→ 后目标（今年要到的阶段成果、完成时间、验证方式），再放回九宫格。

随后用 SMART 与时间估算检查目标是否合理，并根据现阶段需求选出重点领域。

本插件的八个领域（可编辑目标、可标重点）：

| 位置 | 领域 |
| --- | --- |
| 左上 / 中上 / 右上 | 学习成长 / 体验突破 / 休闲放松 |
| 中左 / 中右 | 工作事业 / 家庭生活 |
| 左下 / 中下 / 右下 | 身体健康 / 财务理财 / 人际社群 |
| 中心 | 年度主题 + 五年后想过的生活 |

## 功能

- 左侧栏图标 + 整页面板（`sidebar.panellist` + `main` 键位 `life-grid`）。
- 每个领域可添加多条目标：目标正文 + 完成标准/验证方式（可选）。
- 星标标记「今年重点领域」；空领域会提示，帮助发现遗漏。
- 中心格写年度主题与五年愿景。
- 按年度保存，右上角可切换上一年/下一年、一键回到今年。
- 导出 JSON 备份、导入 JSON（按年度合并）、复制为 Markdown（便于打印或贴进笔记）。
- 中英文文案走 Client `locale` 服务；颜色全部使用 `--dsw-alias-*` 主题 token，跟随浅色/深色主题。
- 内置「怎么用」说明，内容按书中第二章整理。

## 数据

数据保存在当前浏览器 `localStorage`（键 `dsh-life-grid/v1`），按年度各一份；不经过
Host、不上传。**建议定期用右上角「导出 JSON」备份**；导入时按年度合并，不会删除本机其他年度。

## 结构

| 文件 | 作用 |
| --- | --- |
| `package.json` | 包清单：`dsh.bundle.patch` + `dsh.client`（web，立即加载） |
| `cordis.patch.yml` | 插入 Host 行 `life-grid` |
| `index.js` | Host 半：空实现，只提供插件清单条目 |
| `client.js` | 浏览器半：九宫格页面、侧栏图标、数据读写、i18n、样式 |
| `locale/en.json`, `locale/zh.json` | 插件管理器标题与描述 |
| `icon.svg` | 原创图标（九宫格，中心格高亮） |

## 安装

通过 DSH 的 Plugin Manager 安装本目录（bundle），或在会话里由 Agent 执行
`plugin_manager install_bundle`，target 指向本目录绝对路径。安装后左侧栏出现九宫格图标。
